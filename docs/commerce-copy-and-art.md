# Commerce copy and custom artwork

The public proposition is now one commerce backend for inventory, orders, payments and receipts across a website, WhatsApp and the counter. Preserve warm paper surfaces, expressive Nunito, green/terracotta, dimensional artwork and the animated phone.

The platform is in development. Pilot timing, pricing, provider approval, storefronts, official WhatsApp automation, existing-store integrations and voice must not be described as already available. Proposed plan comparison: NGN 5,000 pilot / 10,000 Store / 20,000 Connected. No subscriptions are sold on this site. No fake customer results, automatic tax filing, validated multilingual coverage, screenshots-as-proof, universal undo or unverified regional-hosting claims.

Built-in image generation was used, requesting highest available quality/resolution in all three prompts. This interface exposes no numeric quality selector; maximum quality is a prompt request, not a verified model parameter.

Prompt set: (1) one front-facing forest-green ceramic/enamel button surface, cream rim, empty dark centre for live HTML text, 3:1, transparent, no labels/icons; (2) compact three-quarter tactile stock shelf, cream boxes, terracotta shoe box, forest-green bag and blank inventory tag, transparent, no text; (3) compact tactile sage storefront, green door, cream/terracotta awning and parcel, transparent, no text. All use upper-left studio lighting and premium handmade materials. Exact generation prompts are in the session tool calls.

Project assets: public/brand/commerce/button-enamel.webp, inventory.webp, storefront.webp. Full-resolution generated originals are retained in generated_images by the generation tool. Web delivery copies preserve alpha, with 1000px button and 720px component illustrations. Combined delivery size is approximately 98KB. Labels, state, links and focus remain live HTML/CSS. Artwork is decorative and must not block actions if loading fails.

QA: run npm test, contrast measurements, source audit for retired claims. Browser rendering is unavailable in this managed environment without control-browser; do not claim visual bounds, alpha compositing across themes or keyboard traversal were inspected in a rendered browser.
